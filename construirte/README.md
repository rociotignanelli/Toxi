# Construirte

Catálogo de productos hecho con HTML, CSS y JavaScript puros, sin dependencias. Diseño en negro y rojo.

Para verlo, abrí `construirte/index.html` en el navegador.

## Archivos
- `index.html`: estructura de la página
- `styles.css`: estilos
- `script.js`: catálogo, filtros por categoría, buscador, detalle del producto y carrito (se guarda en el navegador)
- `productos.js`: lista de 526 productos (nombre, categoría, subcategoría, código, descripción, precio de lista e imagen). La página muestra el precio ya ajustado.
- `logo.svg`: logo de Construirte
