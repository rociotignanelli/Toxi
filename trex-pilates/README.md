# Trex Pilates — Tienda

Página de productos de Trex Pilates (negro y azul neón). Abrí `index.html` en el navegador.

- `logo.svg` / `favicon.svg`: logo de la marca.
- `video/portada.mp4`: video de portada (sin audio, se reproduce solo). `video/trex-pilates-con-audio.mp4` es la misma versión con sonido.
- `descriptions.js`: descripción completa de cada producto (por número de producto), que se ve al abrir la ficha.
- `script.js`: lista de productos y precios (`PRODUCTS`) y número de WhatsApp (`WHATSAPP`) al que llegan los pedidos del carrito.
- Fotos: están en `img/` (01.webp … 30.webp, una por producto) con el sello de Trex Pilates. Para cambiar una, reemplazá el archivo con el mismo nombre. Si un producto no tiene `img`, se muestra una ilustración.
