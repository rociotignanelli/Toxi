# Trex Pilates — Tienda

Página de productos de Trex Pilates (negro y azul neón). Abrí `index.html` en el navegador.

- `logo.svg` / `favicon.svg`: logo de la marca.
- `script.js`: lista de productos y precios (`PRODUCTS`) y número de WhatsApp (`WHATSAPP`) para recibir pedidos.
- Fotos propias: guardalas en una carpeta `img/` y agregá `img: "img/archivo.jpg"` al producto. Sin foto, se muestra una ilustración.
  Tu logo aparece como sello en la esquina de cada foto.
